# 🎮 Maze Game

A simple maze game built using HTML, CSS and JavaScript.

## Features

- 🧱 Maze gameplay
- 🎮 Keyboard controls
- 📱 On-screen controls
- 🏠 Goal
- 🔄 Restart button
- 🏆 Win condition

## Files

- `index.html` — Game structure
- `style.css` — Game design
- `script.js` — Game logic

## How to Run

Download the three files and open `index.html` in a browser.
